## Descrição

Sistema de caixa eletronico feito em C rodando pelo terminal. O usuario pode consultar saldo, depositar, sacar e ver o extrato das ultimas operacoes. O projeto usa switch-case, funcoes e loop do-while como pedido pelo professor.

## Funcionalidades

- Consultar saldo
- Depositar valor
- Sacar valor (limite de R$ 500 por operacao)
- Extrato com as ultimas 3 operacoes

## Como compilar e rodar

gcc atm.c -o atm.exe
atm.exe
